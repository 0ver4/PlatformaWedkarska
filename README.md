# Projekt Inżynieria Oprogramowania
> Platfoma GdzieRyba.pl dla wędkarzy - znajdź łowisko, zarezerwuj stanowisko, pochwal sie rekordem.

## O projekcie
**GdzieRyba.pl** to system rezerwacji stanowisk wędkarskich wzbogacony o ewidencję rekordów połowów. Platforma zrzesza wędkarzy oraz właścicieli łowisk komerycjnych i PZW, zastępując czasochłonny proces telefoniczny, wygodnym i przejrzystym miejscem w sieci.

## Funkcjonalności 
- **Rezerwacja online** - wybierz stanowisko, sprawdź dostępność, zarezerwuj z kalendarza.
- **Tablica rekordów** - zgłaszaj swoje połowy i rywalizuj ze społecznością.
- **Interaktywna mapa łowisk** - przeglądaj i filtruj łowiska.
- **Panel zarządcy** - właściciele łowisk zarządzają terminarzem, rezerwacjami i stanowiskami.
- **Panel aministratora** - moderacja kont użytkowników, łowisk i rekordów.
